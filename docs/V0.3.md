# V0.3 — Production Foundation

V0.3 hardens the V0.2 architecture into a SaaS foundation.

## Pipeline
Campaign → provider → normalization/dedup → website enrichment → public contact extraction → evidence → opportunity detection → AI research → scoring → CRM-ready handoff.

## Included
- Multi-tenant organizations and memberships
- OWNER/ADMIN/MEMBER/VIEWER authorization checks
- JWT authentication
- API keys stored as hashes + revocation
- Audit log
- Helmet, CORS and rate limiting
- Encrypted integration secrets
- Monthly usage metering and plan limits
- Idempotency-key data model
- BullMQ durable jobs, retries, exponential backoff and worker concurrency
- Demo discovery provider + optional Apify adapter
- Website crawling with timeout
- Public email extraction/classification
- Evidence and opportunity records
- OpenAI-compatible research adapter with deterministic fallback
- Lead status pipeline, filtering and CSV export
- PostgreSQL + Redis
- Docker Compose
- Health/readiness endpoints

## Plans
FREE 100 · STARTER 1,000 · GROWTH 10,000 · PRO 50,000 · AGENCY 250,000 · ENTERPRISE 1,000,000 monthly units.

## Launch hardening still required
1. Argon2id instead of demo SHA-256 password hashing.
2. Secure HttpOnly cookie sessions + CSRF and session revocation.
3. Email verification, reset and MFA.
4. Do not run migrations from every API boot in production.
5. Managed Postgres/Redis with backups/TLS.
6. SSRF-safe crawler with private-IP, metadata-IP, redirect and DNS-rebinding defenses.
7. Provider-specific terms/compliance review and suppression/opt-out controls.
8. Secret manager, OpenTelemetry/error tracking and alerting.
9. Billing integration.
10. E2E/load/security tests.
